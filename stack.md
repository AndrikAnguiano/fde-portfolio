\# The GenAI stack of: Claude



\## 1 Models          The Claude language model that generates every answer.

\## 2 Context         The conversation history, files and screenshots I share, and instructions that ground its answers.

\## 3 Tools           Web search, reading files, running code and connecting to apps, so it can act beyond just writing text.

\## 4 Orchestration   Deciding which steps to take and in what order, such as searching first, then reading a file, then answering.

\## 5 Trust           Safety rules, refusing harmful requests and asking permission before acting on my computer or accounts.

\## 6 Operations      Hosting, usage limits, monitoring and model updates that keep it running and improving.
